## Tic-Tac-Toe

[`tic-tac-toe.html`](tic-tac-toe.html) is a single-file, mobile-friendly Tic-Tac-Toe
game — no build step, no dependencies, no server required.

- **Play instantly in the browser (no download):** [Open the game](https://htmlpreview.github.io/?https://github.com/cloudboy1975/upgraded-broccoli/blob/claude/tic-tac-toe-browser-game-tex1j7/tic-tac-toe.html)
- **Or run it locally:** download `tic-tac-toe.html` and double-click it (or drag it into any browser tab).

Features:
- Vs Computer (unbeatable minimax AI) or Vs Friend (local 2-player) modes
- Responsive layout that looks good on phones
- Win highlighting, score tracking (saved locally), and a "New Round" reset
